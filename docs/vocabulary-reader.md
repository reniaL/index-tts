# 词表朗读

使用 IndexTTS-2.5 启动 WebUI，打开“词表朗读”标签页。此页复用已加载的模型，和普通朗读共用推理锁及串行队列。

1. 上传参考录音，或从已有音色预设加载参考录音。这里只复用预设的音色录音；语言固定为英语，情感来自该录音。
2. 每行输入一项，单词、短语、句子均可。空行和首尾空格会被移除，重复项及项目顺序保留。先清理停顿占位符、标题、列表编号和 `sth` / `sb` 等缩写。
3. 设置重复次数、同项间隔、不同项间隔和时长系数。默认每项两遍、同项间隔 0.8 秒、不同项间隔 1.5 秒；时长系数大于 1 表示放慢。
4. 点击“生成新词表任务”，查看逐项状态。完成后选择项目试听，必要时仅重生成该项。失败时保留其他成功音频，通过“重试所有未完成项”继续。
5. 调整重复、间隔或首尾裁剪设置后，点击“按当前设置重新拼接”。此操作复用原始音频，不调用模型。修改词表、参考录音或时长系数则需生成新任务。
6. 试听整份音频，通过“下载整份 WAV”保存。最后一项末尾不额外插入换词间隔。

## 音频和任务记录

任务保存于 `outputs/vocabulary/<任务编号>/`，包括参考录音副本、原始音频、处理版本、合并 WAV 和 `task.json`。原始音频与历史导出保留，以便对照；任务目录显示在页面中。生成数据属于本机私有内容，不应提交到 Git。

音频统一为单声道 PCM16 WAV；不同采样率会在拼接前转换。停顿按 `round(采样率 × 秒数)` 插入，记录中保存实际采样点数和总长度。音频自身带有的首尾空白会增加实际听感间隔。

首尾裁剪默认关闭。开启时按短帧音量检测两端空白，并在检测到的边界外保留 80 毫秒余量；弱辅音、轻声和噪声可能影响边界判断，需与原始版本对照试听。所有静音音频保持原样，不强行裁短。

单项重生成使用该任务创建时的参考录音、语言和时长系数。重生成失败会将该项标为失败，当前整份结果撤下；重试成功后才重新导出，避免漏项。旧版本仍保存在任务目录中。

页面会话保存当前任务编号。刷新页面或重启服务后，现有任务文件仍在磁盘上；本版尚未提供历史任务载入界面。

## 验证

CPU 测试可执行：

```powershell
python -m unittest discover -s tests -p test_vocabulary_reader.py -v
```

测试覆盖顺序与重复项、精确停顿、末尾处理、采样率和声道转换、保守裁剪、失败后的恢复，以及仅重生成选中项目。实际模型生成和网页下载还需在启动 WebUI 后检查；发音、音色、词尾完整性和手机播放效果需试听验收。

本次集成验证已使用项目示例录音生成 `ignore`、`gap`、`independent`、`relative`、`code`、`coder`、`professional` 七项。通过 Gradio 客户端验证了整份 WAV 下载与本机文件哈希一致、插入静音和总长度采样点数正确、调整间隔复用单项音频，以及单项重生成仅更新选中项目。普通朗读生成和返回音频也已复验。

浏览器视觉检查受自动化工具限制尚未完成；以上接口和文件验证不代表已完成发音、音色或手机端试听验收。
